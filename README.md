# Ayesha Fazil · Portfolio

Personal portfolio of Ayesha Fazil, full stack developer and social media marketer based in Rawalpindi.

**Live:** https://ayesha-portfolio-inky-theta.vercel.app

## What's inside

- **Software projects:** SaaS Business Product (.NET 10, React, Flutter) and FormBuilder (React, .NET 9)
- **Websites:** BIIT, Northern University, Royal Boots and Pearl Studio
- **Marketing:** social media, client dealing and business development for brands in Dubai
- **Contact:** Gmail, Outlook, LinkedIn and GitHub

## Files

| File | Purpose |
|------|---------|
| `index.html` | The page: content, layout and page-specific styles |
| `core.css` | Shared styles: background light, grain, glass effect, reveal animation |
| `core.js` | Shared behaviour: animated background, scroll reveal, copy email, local time |
| `assets/` | Website screenshots used in the Websites section |

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to view it locally.

## Deploy

Hosted on Vercel as a static site. Every push to `main` deploys automatically.
